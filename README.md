# 🍨 Gelato Ice Cream Shop Website

A modern, responsive multi-page e-commerce website for a fictional **Gelato Ice Cream Shop**, built using **HTML5, CSS3, and Vanilla JavaScript**. This project showcases responsive web design, reusable UI components, interactive shopping features, and client-side state management.

> * **Project Type:** Individual Project
> * **Organization:** Sister of Code Club
> * **Project Lead (Instructor):** Vin Sophannary
> * **Mentor:** Eang Sreynich

---

# 📖 About the Project

The **Gelato Ice Cream Shop Website** was developed as an individual project to apply front-end web development concepts learned during the Sister of Code Club programme. The goal was to create a realistic online ice cream shop that delivers an enjoyable browsing experience while demonstrating clean code organisation, responsive layouts, and interactive user interfaces.

The website allows users to:

* Browse featured gelato products
* View detailed product information
* Add products to a shopping cart
* Register and log in
* Manage their account
* Learn about the business and services
* Contact the shop

The project follows a modular folder structure that separates reusable components, page-specific styles, JavaScript modules, and data, making the codebase easier to maintain and scale.

# 💡 Challenges & Solutions

| Challenge                                           | Solution                                                                    |
| --------------------------------------------------- | --------------------------------------------------------------------------- |
| Maintaining consistent design across multiple pages | Created reusable CSS components for buttons, cards, navigation, and footer. |
| Responsive layouts for different screen sizes       | Used Flexbox, CSS Grid, and media queries.                                  |
| Shopping cart management                            | Implemented Local Storage to persist cart data.                             |
| Authentication without a backend                    | Simulated login and registration using Local Storage.                       |
| Organising a growing codebase                       | Separated page-specific styles and scripts into dedicated folders.          |
| Creating a smooth hero slider                       | Used JavaScript with CSS transitions for seamless animations.               |
